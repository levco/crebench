# Research v1 diagnostic execution

This implements the 24 common-corpus case slots in the research design. It does not claim the independent reviewer qualification or held-out evaluation proposed there: all cases are original synthetic diagnostics, generated in four task families with shared templates. Source extracts are supplied inline to every participant. No real customer or prospect records are redistributed.

Each of 24 cases is attempted once by Lev's native Agent, GPT-5 direct, Opus 5 direct, GPT-5 with generic tools, and Opus 5 with the same generic tools: 120 planned runs. The first four cases (two sales and two sponsor cases) are run first to detect infrastructure problems, but remain in the recorded cohort. Any protocol change after a result is visible requires a new version with the original preserved. No selective quality reruns or substitutions. Existing financing scores remain unchanged.

Native runs use fresh chats in the authorized test account and the exact packet text. Generic tools are arithmetic, CSV writing and the existing generic XLSX writer. Both agents receive the same tools. Direct controls answer the same research questions without artifact tools. Record exact model IDs, provider responses, prompts, tool calls, attempt costs, packet hashes and original artifacts. Native internal prompts/account data remain private; publish only sanitized benchmark-specific response and audit evidence.

The initial API conservative reservation is capped at $45 for this cohort. Native and discovery inference must fit the user's remaining $200 project authorization after earlier recorded consumption. API reservation includes attempts with unreported cost. Record native inferred cost separately from product credits. The experiment does not authorize purchases of contact datasets, outreach, new recurring subscriptions, or access changes.

Before using a native run in a same-data claim, inspect its visible tools and available trace evidence for external lookup, other deals or CRM retrieval. Record violations and audit coverage. Unknown audit coverage is not a confirmed pass. A native result may still be published with access unverified, but must be separated from confirmed common-corpus results.

Scoring follows the public grader and key. Eligibility decisions cover all twenty records before deduplication; duplicate valid records can be eligible, but cannot add shortlist slots. Shortlist yield uses unique eligible/verified entities divided by the smaller of requested count and available unique eligible count. Zero-match cases have separate correct-abstention results and no invented yield percentage. Precision is shown alongside yield. Ranking reports pairwise agreement with the brief's objective ordering on unique eligible returned entities, with pair count disclosed; incomplete and invalid selections still reduce coverage.

Verified yield requires eligibility, unique entity, the requested slot limit, every required fact, and supporting base/controlling-update IDs. Sources of duplicate records can support the same underlying entity. An SPV mapped to its operating sponsor requires both source relationships. Citation dumps of unrelated sources fail. Numeric tolerance is max($0.01 or 0.01 units as applicable, 0.001% of expected value). Numeric material errors exceed max(0.01, 1%); categorical false facts, asserted unknown fields, invented records, duplicate entities and ineligible selections are listed separately as consequential findings. Optional unpublished contacts remain explicitly null. Prose rationale quality is not represented as deterministically expert-reviewed.

Artifact checks: (1) a readable original file exists in the required format, (2) selected record identity and order match the answer, (3) required selected facts including explicit unknowns match the answer, (4) original source identifiers are carried into the file. These measure consistency with the answer; truth remains a separate score. Render comp grids and inspect column/header readability. Do not repair model artifacts after delivery. Generic rendering assistance and the bundled XLSX runtime limitation remain disclosed.

The separate discovery condition needs its own frozen briefs, access inventory, source verification and cost records. No common-corpus result can be advertised as live comp or lead discovery performance. No web-wide recall, customer conversion, outreach deliverability, appraised value accuracy, or independent-review claim follows from this release.

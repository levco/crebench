# Contributing

Open an issue with the task, expected behavior, observed behavior, case/release ID and a minimal reproduction. Do not attach customer data, private keys, personal information or protected test material.

For a rubric dispute, identify the criterion and supply an alternative grounded interpretation. A verified scoring defect must be corrected across every affected system and recorded in a new release; no participant receives a selective repair.

For cases, first propose the task and document provenance without uploading the files. Each accepted case needs publication rights, source locators, independent answer review, a deal-cluster split assignment and negative examples. Contributions require explicit rights to license the material.

For code, run `npm test`, `npm run build` and `npm run check:site`. Grader changes need a counterexample showing why they matter. Do not label deterministic fixtures or generated reference answers as model runs.

Model submission ingestion is not implemented in 0.1.0. The later protocol will require complete manifests, first-run outputs, tool traces, usage, errors and coverage. No leaderboard row is accepted from an unsupported screenshot or self-reported score.

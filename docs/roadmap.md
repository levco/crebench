# Implementation roadmap

| Stage | Deliverable | Acceptance |
|---|---|---|
| Foundation | Public case, grader, website and CI | Reproduce from a clean checkout; incorrect outputs fail |
| Ingestion | XLSX, PDF, scan and lease cases | Rights-cleared diverse sources, verified locators and reviewed keys |
| Financials | Reconciliation and debt-sizing coverage | Independent arithmetic and convention review; false-conflict controls |
| Work products | Underwriting and OM validators | Recalculation probes, native-file inspection and rendered usability checks |
| Execution | Model and Lev adapters | Isolated inputs, precise versions, full traces, usage and failure records |
| Pilot | Development-only comparisons | Cost and variance measured; grader/runner defects resolved |
| Evaluation | Frozen held-out cohort | Independent review, no deal leakage, run budget and complete coverage |
| Release | Results and evidence | Task-level findings, paired uncertainty, licensed reproduction and corrections |

Dependencies: representative documents and release rights, qualified CRE reviewers, precise Lev test access, evaluation credentials and budget, and domain DNS configuration. Do not replace absent resources with claims that the corresponding stage is complete.

# Website design

The site is a research instrument for a CRE professional. Its memorable element is an interactive source-to-answer workbench: a rent-roll or T-12 excerpt beside the checked result and source location. No fictional model leaderboard.

Palette: deep navy #173248, paper white #ffffff, cool background #f2f5f8, slate #526573, blue #2363c6, line #d9e2e9. Georgia display text evokes the narrative in a deal memorandum; system sans-serif handles dense tables and navigation. Numerals use tabular figures.

Layout: left-aligned title and quiet status note; an asymmetric workbench shows the actual work. Below, a three-stage document-to-underwriting sequence links to task families. A compact navigation supports Method, Tasks, Results and Reproduce. Mobile stacks the evidence panels and keeps controls reachable.

Review: avoid a decorative building hero, synthetic score cards and long engagement prose. Color encodes source selection and pass/fail, not arbitrary decoration. Status labels are always text, never color alone. Tables scroll inside their bounds. Keyboard focus and reduced motion are supported.
